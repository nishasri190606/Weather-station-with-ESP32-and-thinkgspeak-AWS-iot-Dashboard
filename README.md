DHT22 Temperature and Humidity Monitoring using ESP32 and ThingSpeak

Project Description

This project monitors real-time temperature and humidity using an ESP32 microcontroller and a DHT22 sensor.

The collected sensor data is transmitted to the ThingSpeak cloud platform through Wi-Fi.

Components Used

- ESP32
- DHT22 Temperature and Humidity Sensor
- Wi-Fi Connectivity
- ThingSpeak Cloud Platform

Working Principle

1. The DHT22 sensor measures temperature and humidity.
2. ESP32 reads the sensor values.
3. ESP32 connects to Wi-Fi.
4. The measured data is uploaded to ThingSpeak.
5. Temperature and humidity values are displayed as real-time graphs.

Applications

- Weather Monitoring
- Smart Home Monitoring
- Environmental Monitoring
- IoT-Based Monitoring Systems
